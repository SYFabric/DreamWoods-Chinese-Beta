- 汉化内容：剧情对话、教程、部分 UI

## 2 代（DreamWoods2）

- 文件：`梦幻森林2代小布汉化1.0Beta.part1/part2.zip`
- 汉化内容：
  - 全部窗口类 UI（选项/暂停/地图/神器/奖励/帮助/提示框）：中文
  - 全部剧情对话（213 条）：中文
  - 章节地图背景：已加入汉化者版权文字（右下角）
  - 动态指示文本（找乌鸦/找青蛙提示、关卡旗帜等）：保留英文（引擎 GText/GFont 系统只支持英文字形）
  - 主菜单问候 "Hello, "：保留英文（同上原因）
- 说明：下载两个 part，用 7-Zip 解压 part1（自动合并）

## 通用

1. 下载对应的 part 文件
2. 用 7-Zip 解压 part1（会自动合并 part2）
3. 解压到游戏目录覆盖原文件
